# تطبيق الطقس 🌤️- Weather App

## عن المشروع (Arabic)
تطبيق طقس عملي يتيح للمستخدم معرفة حالة الطقس لأي مدينة , مع ميزات إضافية لتحسين تجربة المستخدم

**الميزات:** 
- البحث عن أي مدينة والحصول على بيانات الطقس (الحرارة , الرطوبة , الرياح , وصف السماء )
- دعم اللغتين : الإنجليزية والعربية , مع حفظ التفضيلات
- وضع الليلي والنهاري (Light Mode , Dark Mode) مع حفظ التفضيلات
- تصميم متجاوب يعمل على جميع الأجهزة

  ## About (English)
  Weather App That Provides The User To Know The Weather Conditions For Any City , With Additional Features To Improve The User Experience

  **Features:**
  - Search For Any City And Get Weather Data (Temperature , Humidity , Wind , Sky Description)
  - Supports For Two Languages : Arabic , English , With Save Prefrences
  - Dark/Light Mode With Save Prefrences
  - Responsive Design That Work On All Devices

## التقنيات المستخدمة / Teck Stack 
- **HTML5** , **CSS3** (FlexBox , Grid , Css Variables)
- **JavaScript (ES6)** (Fetch API , LocalStorage , DOM Manipulation)
- **OpenWeatherMap API** (للحصول على بيانات الطقس)
